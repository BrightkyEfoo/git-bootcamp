## 🎬 Module 8 – Démo finale & Q/R (1 h)

---

### 1. Démonstration complète du cycle GitHub

* **Création d’une branche** (`feature/ma-fonctionnalite`) à partir de `dev` ou `main`
* **Push** des commits avec messages clairs (respect des Conventional Commits)
* **Ouverture d’une Pull Request** avec description complète et checklist
* **Assignation automatique des reviewers** via `CODEOWNERS`
* **Processus de revue et approbation**
* **Merge** via squash & merge ou merge classique selon la stratégie
* **Déclenchement automatique** du workflow CI (tests, build) via GitHub Actions
* **Création automatique d’une release** ou draft release
* **Déploiement** vers un environnement (exemple Vercel, AWS, ou autre)
* Suivi des logs et monitoring post-déploiement

> Cette démo permet de lier tous les concepts abordés, avec un focus sur l’automatisation et la qualité.

---

### 2. Session Questions / Réponses & Partage d’expériences

* Temps dédié aux interrogations des participants
* Partage de bonnes pratiques et retours d’expérience
* Discussion sur les cas spécifiques rencontrés en entreprise ou projets personnels

---

### 3. Roadmap post-bootcamp

* Conseils pour implémenter progressivement les bonnes pratiques dans ses projets
* Outils et ressources recommandés pour approfondir :

  * Documentation officielle Git & GitHub
  * Tutoriels avancés (GitHub Actions, CLI, sécurité)
  * Communautés et forums
* Proposition d’un plan d’auto-formation continue
* Suggestions pour mise en place d’un **GitHub handbook** interne dans les équipes
